# 010.040 — Mock provider

**Critical path.** Nothing in the harness engine is testable until this exists.
Build it first, before Google, before Ollama, before the trait cleanup ships.

The old TypeScript had one (`providers/mock.ts`, 342 lines) and it is why their
tests were runnable at all.

## Where it lives

In `cosmos-llm` proper, behind a `mock` feature enabled by default in dev and test.
Not in a separate crate: every consumer of `cosmos-llm` needs it for their own
tests, and a `dev-dependency` on a testing crate that itself depends on
`cosmos-llm` creates a cycle.

## Microsteps

### 010.040.010 — Scripted responses

```rust
let provider = MockProvider::new()
    .respond("first answer")
    .respond_with_tool_call("web_search", json!({"query": "x"}))
    .respond("final answer");
```

Responses are consumed in order. Running past the end is an error naming how many
were consumed — a test that silently reuses the last response hides bugs.

### 010.040.020 — Streaming that matches non-streaming

The mock must emit chunks that, fed through `StreamAccumulator`, reconstruct
exactly the response its non-streaming path returns. That equivalence is the
property the harness's streaming tests assert
([`../PLAN/030.060`](../PLAN/030.060.000-streaming.md)), so the mock has to model it
correctly or the tests are theater.

Configurable chunking: per-character, per-word, per-arbitrary-boundary, including
splitting a tool-call JSON argument mid-token. That last case is where real
streaming accumulators break.

### 010.040.030 — Failure injection

```rust
.fail_with(CosmosError::RateLimit { retry_after: Some(Duration::from_secs(20)) })
.fail_times(2).then_respond("ok")     // for retry tests
.delay(Duration::from_millis(500))    // for timeout and concurrency tests
.fail_mid_stream_after(3)             // chunks, then error
```

Retry ([030.010](030.010.000-retry.md)) and fallback
([030.020](030.020.000-fallback.md)) cannot be tested without this.

### 010.040.040 — Request capture

Every request received is recorded and inspectable:

```rust
assert_eq!(provider.requests()[0].messages.len(), 3);
assert!(provider.requests()[0].tools.is_some());
```

This is how the harness tests context assembly and trimming
([`../PLAN/030.020`](../PLAN/030.020.000-context-assembly.md)) without a network.

### 010.040.050 — Deterministic canned behaviors

A few built-in modes for tests that do not care about specifics:
`echo` (returns the last user message), `count` (returns the message count),
`fixed(s)`. Keeps simple tests from needing three lines of setup.

### 010.040.060 — Usage reporting

The mock reports plausible token counts derived from actual message lengths, so
usage-accounting tests ([030.030](030.030.000-usage-and-cost.md)) have something to
assert against.

## Ruby note

`lib/ruby/cosmos-llm-ruby-client` should get the equivalent when the gems are
ported. Same builder shape where Ruby idiom allows — a developer moving between
the two should recognize it.

## Verification

- Streaming and non-streaming paths produce identical `CompletionResponse`s for
  every configured chunking strategy.
- Tool-call arguments split across chunk boundaries reassemble correctly.
- Failure injection produces the exact error variants requested.
- Running past the end of the script errors with a clear message.
